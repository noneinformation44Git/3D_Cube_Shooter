# 3D Cube Shooter 0_o

A retro-styled 3D first-person shooter prototype built from scratch using **Java** and the **libGDX** framework.

This project was created as a hands-on sandbox to experiment with 3D math, perspective cameras, custom texture mapping, and reactive AI behaviors.

## 🚀 Key Features
* **Advanced Enemy AI:** Foes don't just mindlessly charge at you; they actively navigate around columns and crates using obstacle avoidance routines.
* **BunnyHop Mechanics:** Includes an old-school momentum system. Hold space to auto-jump and continuously build up speed!
* **Destructible Environment:** Break wooden crates to scavenge resources and restore your health (+20 HP).
* **Smooth UI Matrix:** Built-in dynamic projection matrix tailored for Full HD monitors (1920x1080).

## 🎮 Controls
* **W, A, S, D** — Movement (Relative to look direction)
* **SPACE** — Hold to BunnyHop and gain speed
* **LEFT SHIFT** — Tactical Dash
* **Left Mouse Button (LMB)** — Shoot
* **ESCAPE** — Release mouse capture / Return to Main Menu
